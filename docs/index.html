How it works

  1. Transactions are validated.
  2. Python applies BUY/SELL rules.
  3. Holdings are reconstructed from history.
  4. Portfolio metrics are derived from the resulting state.

The GitHub Pages demo is a lightweight browser presentation layer. The canonical implementation is the Python package in portfolio_tracker/.
